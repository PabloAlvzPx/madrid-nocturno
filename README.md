# Madrid Nocturno: Reparto Exprés — juego generado por IA

Minijuego de navegador en el que conduces una moto de reparto por Madrid de noche: recoges el pedido en la taberna, esquivas el tráfico y lo entregas antes de quedarte sin gasolina.

Lo generó **Gemini 4** como parte de una prueba de mi colaboración con un canal de YouTube que compara modelos de IA.

🎮 **Jugar:** https://pabloalvzpx.github.io/madrid-nocturno/

## Qué hice yo

- Ejecuté la prueba con el modelo y registré el proceso.
- Evalué el resultado: si el juego cumplía el encargo, si funcionaba sin errores y si era jugable en escritorio y móvil.
- Revisé y publiqué el proyecto.

## Qué incluye el juego

- Un solo archivo HTML, sin dependencias ni librerías externas.
- Juego en `<canvas>` con colisiones, combustible y temporizador.
- Controles con teclado (WASD o flechas) y botones táctiles para móvil.
- Control de velocidad, pantalla de instrucciones y pantalla de resultados.

## Tecnologías

HTML · CSS · JavaScript (Canvas API)

## Nota

El código fue generado por IA. Mi trabajo fue la ejecución de la prueba, la evaluación del resultado y la publicación.
